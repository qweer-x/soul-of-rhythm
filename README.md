# 音乐画布 · 2D / 3D 音频生成艺术原型

这个原型把同一首音乐凝固成两类永久作品：

- **2D 音乐绘画**：歌曲时间推动画面从左向右完成；已经生成的色场、地景、笔触和声音印记不会消失。
- **3D 音乐建筑**：结构沿时间在空间中持续建造；已经生成的主干、地基、门庭、节点和光体保持静止，并最终共同组成整首歌的形状。

2D 与 3D 都采用可扩展的“创作语言”系统。被保留的方案会成为独立风格，后续实验不会覆盖已有版本；切换风格、色彩、随机种子或细节密度时，作品会按照当前播放位置确定性重建。

## 2D 创作语言

### 风格 1 · 声纹流线

完整保留最初版本。低频形成连续色带，中频形成旋律主线，高频与瞬态形成细线、光点和叶片。它更接近声音轨迹、声纹与生成图案。

### 风格 2 · 声景画卷

重新设计的绘画方案，不再让一条中心曲线统治整幅画：

- 每个音乐段落先成为一幕独立风景，并获得自己的远景、中景、前景、留白和视觉焦点；
- 低频沉积为地形、山体、水岸和前景厚度；
- 中频及主导音高决定树木、亭廊、主体形体与落点；
- 高频生成云气、飞鸟、天空纹理和轻笔；
- 瞬态形成山峰、树干、门廊、刮擦和书写性重笔；
- 所有段落从左向右连接成一幅完整的横向抽象画卷。

## 3D 建筑语言

### 风格 1 · 生长脉络

完整保留原有 3D 方案。音乐沿一条空间脉络连续生长；低频影响主干厚度，中频改变路径，高频生成分支与晶体，瞬态形成节点，段落形成空间环。所有结构生成后永久凝固。

### 风格 2 · 共鸣殿堂

新增的建筑式生成方案，把歌曲建造成一条可进入的空间作品：

- 时间成为连续的建筑轴线和厅室深度；
- 低频铺设连续地基、台阶和空间宽度；
- 中频及音高抬起柱廊、门庭、拱顶和结构比例；
- 高频形成光片、悬挂晶体、环形构件与细部；
- 瞬态触发门廊、祭台、横梁和结构重音；
- 每个段落拥有不同的转向、尺度、入口和核心雕塑，降低路径与构件的机械重复；
- 镜头可跟随生成前沿、自动总览完整作品，或进入手动观察。

当前默认使用两种模式各自的风格 2。风格 1 始终可以从右侧“艺术方向”中切回。

## 直接运行

双击根目录中的 `音乐画布_2D+3D原型.html` 即可。它是自包含文件，不需要安装依赖，也不需要联网。

建议使用已开启硬件加速的最新版 Chrome、Edge、Safari 或 Firefox。3D 模式需要 WebGL；如果浏览器无法创建 WebGL 环境，程序会自动保留可用的 2D 模式。

## 使用步骤

1. 上传 MP3、WAV、M4A、AAC、OGG 或浏览器可解码的 FLAC；也可以点击“播放内置示例”。
2. 等待系统分析节奏、能量、低中高频、主导频率、瞬态和段落。
3. 在顶部切换 2D / 3D，并在右侧选择对应创作语言。
4. 播放音乐，或拖动时间轴查看当前时刻已经完成的作品。
5. 点击“重新生成”更换随机种子；歌曲的结构骨架保留，局部笔法、建筑布局和细节会变化。
6. 调整色彩体系与细节密度；点击“导出画作”保存当前 PNG。

快捷键：`Space` 播放/暂停，`M` 切换 2D/3D。

## 当前实现边界

- 系统根据混音音频中可检测的频谱、能量、主导频率和瞬态事件创作，并不等同于精确识别混音里的每一个真实 MIDI 音符。
- 若后续加入人声、鼓、贝斯、伴奏分轨或 MIDI，视觉事件可以获得更精确的声部和音符级对应。
- 当前导出为 2D PNG 或 3D 当前视角 PNG；尚未加入 GLB/OBJ 三维模型导出和完整生成过程视频导出。
- 风格 2 仍属于开发分支中的实验候选；确认满意后再合并为稳定版。

## 修改源码

需要 Node.js 18+。

```bash
npm install
npm run build
```

源码入口：`src/main.js`；界面样式：`src/styles.css`；页面模板：`src/index.template.html`。

`build.mjs` 会把自包含成品输出到项目根目录中的 `音乐画布_2D+3D原型.html`。
