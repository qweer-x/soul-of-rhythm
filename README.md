# 音乐画布 · 2D / 3D 音频生成艺术原型

这个原型把同一首音乐映射为两种永久生成作品：

- **2D 音乐绘画**：歌曲时间推动画面从左向右完成。所有色场、色块、笔触和声音印记生成后都会保留。
- **3D 音乐建筑**：结构沿时间连续生长；主干、节点、分支、晶体和段落环一经生成便保持静止。镜头可在“前沿跟随”“整体总览”和手动旋转之间切换。

## 2D 创作语言

2D 模式采用可扩展的“创作语言”系统。每一种被保留的生成方式都会作为独立风格存在，之后可以继续加入风格 3、风格 4，而不覆盖前面的版本。

- **风格 1 · 声纹流线**：完整保留最初版本。低频形成连续色带，中频形成旋律主线，高频与瞬态形成细线、光点和叶片。整体更接近声音轨迹与生成图案。
- **风格 2 · 声色画境**：以绘画而不是曲线为目标。段落先决定画面重心、主题形体和留白；音乐再逐层沉积为底层色场、成组色块、干湿笔触、刮刀印记与高频飞白。音高会改变笔触落点，但不再由一条中心曲线统治整张画。

当前默认使用风格 2，可在右侧“艺术方向 → 2D 创作语言”中随时切换。切换风格、随机种子、色彩体系或细节密度时，作品会按照当前播放位置确定性重建。

## 直接运行

双击根目录中的 `音乐画布_2D+3D原型.html` 即可。它是自包含文件，不需要安装依赖，也不需要联网。

建议使用已开启硬件加速的最新版 Chrome、Edge、Safari 或 Firefox。3D 模式需要 WebGL；如果浏览器无法创建 WebGL 环境，程序会自动保留可用的 2D 模式。

## 使用步骤

1. 上传 MP3、WAV、M4A、AAC、OGG 或浏览器可解码的 FLAC；也可以点击“播放内置示例”。
2. 等待系统分析节奏、能量、低中高频、瞬态和段落。
3. 播放音乐，在顶部切换 2D / 3D。
4. 在 2D 模式中选择“风格 1 · 声纹流线”或“风格 2 · 声色画境”。
5. 使用时间轴跳转时，作品会根据当前随机种子和创作语言确定性重建。
6. 点击“重新生成”更换种子；歌曲的结构骨架保留，局部笔法与分支变化。
7. 调整色彩体系与细节密度；点击导出保存当前 PNG。

快捷键：`Space` 播放/暂停，`M` 切换 2D/3D。

## 当前实现边界

- 系统根据混音音频中可检测的频谱、能量、主导频率与瞬态事件作画，并不等同于精确识别混音里的每一个真实 MIDI 音符。
- 若后续加入人声/鼓/贝斯/伴奏分轨或 MIDI，视觉事件可以获得更精确的声部和音符级对应。
- 当前导出为 2D PNG 或 3D 当前视角 PNG；尚未加入 GLB/OBJ 三维模型导出和生成过程视频导出。

## 修改源码

需要 Node.js 18+。

```bash
npm install
npm run build
```

源码入口：`src/main.js`；界面样式：`src/styles.css`；页面模板：`src/index.template.html`。

`build.mjs` 会把自包含成品输出到项目根目录中的 `音乐画布_2D+3D原型.html`。
